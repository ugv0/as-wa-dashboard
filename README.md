## 🎛️ Control Panel Features

- **⚡ Auto-Reply (Master Toggle):** Enable or pause all automated AI replies globally.
- **💬 Only DM Mode:** When active, the bot completely ignores all group messages and only replies in private 1-on-1 chats.
- **🏷️ Self Tag (@Bot):** Toggle reply when someone mentions or tags the bot in a group.
- **↩️ Swipe Reply:** Toggle reply when someone swipe-quotes a message sent by the bot.
- **📢 All Tag (@all / @everyone):** Toggle reply when a group all-tag is used.
- **🧠 Dynamic System Prompt Editor:** Change Nemotron 3.5 Bolt's personality, rules, and prompt in real-time.
- **📊 Live Activity & Conversation Feed:** Real-time incoming messages, filterable by DMs or Groups, showing user text and Nemotron's reply.
